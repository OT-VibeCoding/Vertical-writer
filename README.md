# 縦書きエディター (Vertical-writer)

原稿用紙のようにページ単位で文章を書ける、ブラウザで動く縦書きテキストエディターです。
小説や脚本の下書きを、仕上がりの文字数・ページ数を意識しながら書けるように作りました。

## 使い方

https://shiokara2424.github.io/Vertical-writer/ にアクセス、またはローカルで `index.html` を開く。

スマホではブラウザの「ホーム画面に追加」で、アプリのように使えます（PWA対応）。

## 機能

- 縦書き（右から左へ）での入力・編集
- 1ページの行数（5〜60）と列数（3〜40）を設定でき、1ページあたりの文字数を表示
- ページの区切り線とページ番号を自動で表示
- 文字サイズの変更（10〜36px）
- 文字数のカウント（改行を除く）
- 新規作成・ファイルを開く・別名保存・上書き保存（Ctrl+S）
- 入力内容をブラウザに自動保存し、未保存のまま閉じようとすると警告
- 元に戻す・やり直し
- `//` で始まる行をメモ（コメント）として緑色でハイライト
- 改行記号（↵）の表示切り替え
- 設定内容はブラウザに保存され、次回も引き継がれます

## 工夫した点

- **表示範囲だけを描画して軽く動かす**: ページ区切りや改行記号は、画面に見えている範囲と前後1ページ分だけを描画し、長い文章でも動作が重くならないようにしています。
- **改行の扱いを安定させる**: ブラウザの編集機能（contenteditable）は、改行の内部表現がブラウザや操作によって変わり、そのまま文字を取り出すと改行が重複することがあります。そのため、文書の構造を自前でたどって、文字数カウントや保存用のテキストを正しく取り出しています。
- **書きながら構成メモを残せる**: 行頭に `//` を付けた行をハイライトし、本文とメモを見分けやすくしています。

## 技術

- バニラJS、フレームワーク不使用、単一HTMLファイル
- CSS の `writing-mode: vertical-rl` による縦書き表示
- Canvas によるページ区切り・改行記号・ハイライトの描画
- File System Access API によるファイル保存（対応ブラウザ）
- localStorage による自動保存・設定保存
- PWA（manifest.json / Service Worker）
